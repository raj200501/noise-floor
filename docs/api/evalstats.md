## `evalstats`

evalstats: statistics for eval results.

Paired and clustered comparisons, bootstrap and mixed-model intervals, power and
minimum detectable effects, rank-confidence sets, variance components, and
policy-sensitivity bounds for model evaluation results.

### class `EvalResults(frame: 'pd.DataFrame') -> None`

Validated long-format results table.

Columns: ``model``, ``task``, ``run`` (all stored as strings), ``outcome``
(float in [0, 1]) and any number of covariate columns. Each (model, task, run)
appears once. Build with :meth:`from_frame` or :meth:`from_records`.

- property `covariates`: Columns other than the schema columns.
- property `is_binary`: True if every outcome is 0 or 1.
- property `models`: Model identifiers in first-appearance order.
- `paired(self, model_a: 'str', model_b: 'str') -> 'PairedScores'`: Per-task scores of two models on the tasks both attempted (sorted by task).
- `run_counts(self, model: 'str') -> 'pd.Series'`: Number of runs per task for one model, indexed by task.
- `score(self, model: 'str') -> 'float'`: Benchmark score: mean over tasks of the per-task mean outcome.
- `score_matrix(self) -> 'pd.DataFrame'`: Tasks by models table of per-task mean outcomes (NaN where a model has no runs).
- `subset(self, models: 'Sequence[str] | None' = None, tasks: 'Sequence[str] | None' = None) -> 'EvalResults'`: Rows for the given models and tasks only.
- `task_scores(self, model: 'str') -> 'pd.Series'`: Mean outcome per task for one model, indexed by task.
- property `tasks`: Task identifiers in first-appearance order.

### `bca_interval(values: 'npt.ArrayLike', level: 'float' = 0.95, n_boot: 'int' = 10000, seed: 'int | None' = None) -> 'Interval'`

Bias-corrected and accelerated (BCa) bootstrap interval for the mean.

Acceleration comes from the jackknife over the resampled units (tasks).

### `cluster_robust_mean(values: 'npt.ArrayLike', clusters: 'npt.ArrayLike', level: 'float' = 0.95) -> 'tuple[Interval, float]'`

Mean of observations with a CR1 cluster-robust standard error.

Returns the interval (t with G - 1 degrees of freedom, G clusters) and the
standard error. Every observation weighs the same, so tasks with more runs
weigh more; use :func:`t_interval` on task means for equal task weights.

### `cluster_wilson_interval(task_means: 'npt.ArrayLike', runs: 'npt.ArrayLike', level: 'float' = 0.95) -> 'Interval'`

Wilson interval for a success rate at its design-effect sample size.

``task_means`` are per-task success rates in [0, 1] and ``runs`` the runs behind each;
the estimate is their mean (every task weighs the same). Its variance is the larger of
the task-clustered variance ``sd**2 / T`` and the binomial variance of the same
estimator, ``p (1 - p) mean(1 / runs) / T``, so the effective sample size
``p (1 - p) / variance`` is at most the run count. The Wilson interval at that sample
size uses the t quantile with ``T - 1`` degrees of freedom. Unlike the t interval it
stays inside [0, 1] and keeps its width when most tasks are all-success or all-failure.

### `decompose(results: 'EvalResults', *, random: 'Sequence[str]' = ('task', 'model', 'model:task'), fixed: 'Sequence[str]' = (), level: 'float' = 0.95, intervals: 'bool' = True, backend: 'str' = 'auto', seed: 'int' = 0, method: 'str' = 'profile', n_boot: 'int' = 200, nagq: 'int' = 1, boot_interval: 'str' = 'percentile', box_interval: 'str' = 'percentile', share_interval: 'str' = 'percentile') -> 'Decomposition'`

Fit a logit GLMM and partition the latent variance.

``random`` lists grouping columns (``a:b`` for crossed combinations) given
random intercepts; ``fixed`` lists categorical covariates entered as fixed
effects. Outcomes must be binary. ``method`` picks the lme4 intervals:
``profile`` (profile likelihood) or ``parametric_bootstrap`` (``n_boot``
replicates, each a fresh fit with ``nagq`` = 1 for Laplace or 0 for the faster
approximation, random variances with ``boot_interval``, fixed contributions with
``box_interval``, and shares with ``share_interval``; see the module docstring).

### `design_from_logit(eta_a: 'float', eta_b: 'float', task_var: 'float', model_task_var: 'float', *, nodes: 'int' = 24) -> 'PairedDesign'`

Variance inputs for a paired comparison implied by a logit model of the outcomes.

Model: ``p_m = sigmoid(eta_m + u + v_m)`` for models ``a`` and ``b`` on a task, with
task effect ``u ~ N(0, task_var)`` and independent model-by-task effects
``v_m ~ N(0, model_task_var)``. ``between`` is ``Var(p_a - p_b)`` over the task
population and ``within`` is ``E[p_a (1 - p_a) + p_b (1 - p_b)]`` (one run of each
model per task), both by Gauss-Hermite quadrature with ``nodes`` points per axis.

### `design_from_results(results: 'EvalResults', model_a: 'str', model_b: 'str') -> 'PairedDesign'`

Method-of-moments variance inputs estimated from observed results.

``within`` is the mean over tasks of the unbiased run-level variances of A and
B (tasks where both models have at least 2 runs); ``between`` is the variance
of per-task differences minus their average sampling variance, floored at 0.

### `interval_for_mean(values: 'npt.ArrayLike', method: 'str' = 'cluster_t', level: 'float' = 0.95, n_boot: 'int' = 10000, seed: 'int | None' = None) -> 'Interval'`

Interval for the mean of per-task values by the named method.

Methods: ``cluster_t`` (t interval on task-level values), ``bootstrap``
(percentile, resampling tasks), ``bca`` (bias-corrected and accelerated). For a
success rate, :func:`cluster_wilson_interval` (``score_interval(method=
"cluster_wilson")``) also needs each task's run count, so it is not listed here.

### `mde(design: 'PairedDesign', n_tasks: 'int', runs_per_task: 'int' = 1, *, alpha: 'float' = 0.05, power: 'float' = 0.8, two_sided: 'bool' = True) -> 'float'`

Smallest true score difference detected with the given power and level.

### `mover_wilson_interval(a_means: 'npt.ArrayLike', a_runs: 'npt.ArrayLike', b_means: 'npt.ArrayLike', b_runs: 'npt.ArrayLike', level: 'float' = 0.95) -> 'Interval'`

Interval for the paired difference of two success rates, ``a - b``, on shared tasks.

MOVER (method of variance estimates recovery): each rate gets its
:func:`cluster_wilson_interval`, and the two are combined with ``r``, the correlation of
the per-task rates (0 when either is constant), as
``d - sqrt((p_a - l_a)**2 + (u_b - p_b)**2 - 2 r (p_a - l_a)(u_b - p_b))`` for the lower
end and symmetrically for the upper end. It keeps nominal coverage at success rates near
0 or 1, where the paired t interval on per-task differences under-covers.

### `paired_difference(results: 'EvalResults', model_a: 'str', model_b: 'str', *, method: 'str' = 'cluster_t', level: 'float' = 0.95, n_boot: 'int' = 10000, seed: 'int | None' = None) -> 'PairedComparison'`

Paired comparison on the tasks both models attempted.

``method`` is ``cluster_t`` (default), ``bootstrap``, ``bca``, or ``mover_wilson`` (for
success rates; see :func:`evalstats.intervals.mover_wilson_interval`). The p-value is the
two-sided paired t-test on per-task differences, except with ``mover_wilson``, whose
p-value inverts its interval (:func:`evalstats.intervals.mover_wilson_p_value`); ``se``
and ``t_stat`` are always the paired t quantities.

### `percentile_interval(values: 'npt.ArrayLike', level: 'float' = 0.95, n_boot: 'int' = 10000, seed: 'int | None' = None) -> 'Interval'`

Percentile bootstrap interval for the mean, resampling the given values.

### `policy_bounds(results: 'EvalResults', *, status_col: 'str' = 'status', ambiguous: 'Sequence[str]' = ('infra_error', 'timeout', 'flagged'), policy: 'str' = 'as_scored', level: 'float' = 0.95, reference_order: 'Sequence[str] | None' = None) -> 'PolicyReport'`

Scores under each policy, worst-case bounds, and robustness of adjacent orderings.

Adjacent pairs follow ``reference_order`` when it is given (for a board whose own
scoring rule is none of the named policies), else the ranking under ``policy``,
and use the tasks both models attempted. Each pair's ``difference`` is the
difference under ``policy``.

### `score_interval(results: 'EvalResults', model: 'str', *, method: 'str' = 'cluster_t', level: 'float' = 0.95, n_boot: 'int' = 10000, seed: 'int | None' = None) -> 'ScoreInterval'`

Interval for one model's benchmark score (mean over tasks of task means).

### `t_interval(values: 'npt.ArrayLike', level: 'float' = 0.95) -> 'Interval'`

Student t interval for the mean of independent values (n - 1 degrees of freedom).

Applied to per-task scores or per-task paired differences this is the
task-clustered interval of Miller (2024): runs are averaged within a task first.

## `evalstats.adapters`

Readers that turn benchmark harness outputs into :class:`~evalstats.schema.EvalResults`.

Each reader parses the harness's files directly (standard library and pandas only; the harness
packages are not imported) and adds a ``status`` covariate with one of :data:`STATUSES`, which
the policy-sensitivity bounds use. Each module docstring documents its status mapping.

### `STATUSES`

Value: `('ok', 'infra_error', 'timeout', 'flagged')`

### `read_harbor(job_dir: 'str | Path', *, reward_key: 'str | None' = None, model_label: "Literal['model', 'agent_model']" = 'model', include_incomplete: 'bool' = True) -> 'EvalResults'`

Read Harbor trial results from a job directory (or a trial directory or file).

``job_dir`` is a job directory, a directory of job directories, a trial directory, or a
trial ``result.json``. ``reward_key`` names the reward used as the outcome when the
verifier reports several. ``model_label="agent_model"`` labels models
``<agent>__<model>``. ``include_incomplete=False`` drops the ``infra_error`` rows for trial
directories without a result. The module docstring gives the row layout and the status
mapping. Raises :class:`SchemaError` if a file is not a Harbor result, a reward is
ambiguous, not a number, or outside [0, 1], or no trials are found.

### `read_inspect(path_or_dir: 'str | Path', *, scorer: 'str | None' = None, value_map: 'Mapping[str, float] | None' = None, value_key: 'str | None' = None, run_key: "Literal['epoch', 'eval_epoch']" = 'epoch', include_missing: 'bool' = True) -> 'EvalResults'`

Read Inspect AI eval logs (``.eval`` or ``.json``, a file or a directory of them).

``path_or_dir`` is a log file or a directory searched recursively for logs. ``scorer``
names the scorer whose value is the outcome (default: the first scorer). ``value_map``
gives the outcome of string score values in place of :data:`INSPECT_VALUE_MAP`, and
``value_key`` picks the entry of dict-valued scores. ``run_key="eval_epoch"`` labels runs
``<eval_id>/<epoch>`` so that several logs of one model and task can be read together.
``include_missing=False`` drops the ``infra_error`` rows added for samples a log lacks.
The module docstring gives the row layout, the value mapping, and the status mapping.
Raises :class:`SchemaError` if a file is not a readable Inspect log, a score cannot be
mapped to [0, 1], a log holds one sample and epoch twice, or two logs give the same
(model, task, run).

### `read_swebench(path: 'str | Path', instances: 'Iterable[str] | str | Path', *, model: 'str | None' = None, run: 'str | int' = 0, categories: 'Mapping[str, str] | None' = None, on_unknown: "Literal['error', 'drop']" = 'error') -> 'EvalResults'`

Read one submission's SWE-bench results, one row per instance in ``instances``.

``path`` is a run report, an experiments ``results.json``, a merged per-instance report
file, or a directory with one subdirectory per instance. ``instances`` is the full instance
list: ids, or a path (a ``str`` is always taken as a path) to a text file with one id per
line, a JSON list of ids or of objects with ``instance_id``, or JSON Lines of either.
``model`` labels every row (default: inferred from ``path``) and ``run`` sets the run label.
``categories`` adds or replaces ``results.json`` categories, mapped to a status.
``on_unknown="drop"`` ignores result ids outside ``instances`` instead of raising. The
module docstring gives the formats and the status mapping. Raises :class:`SchemaError` if a
file is malformed or of an unknown format or the instance list is empty.
